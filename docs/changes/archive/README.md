# Shipped change archive

Changes 01–34 are preserved byte for byte in [changes-01-34.zip](changes-01-34.zip).
The original records include Russian prose and exact historical acceptance evidence.
They describe their own implementation date, not today's release or hardware acceptance.
Download and extract the ZIP to read an original named file. The [manifest](index.json)
records each original filename and SHA-256; `npm run check:docs` verifies integrity.
Later shipped changes remain individual Markdown files alongside this index.

## Reading historical records

On Windows, use **Extract All**. In a terminal, run:

```bash
python3 -m zipfile -e docs/changes/archive/changes-01-34.zip /tmp/penable-history
```

New change numbering takes the maximum of active files, individual archived files and
manifest entry numbers, then adds one. Never restart numbering after ZIP compression.
